# SPACEXTEN — лендинг + панель управления

Сайт компании SPACEXTEN: каталог с категориями и подкатегориями, корзина с
оформлением заказа, редактируемые блоки, слайдер, инструкции, заявки, заказы,
соцсети, аналитика, автоматические резервные копии и защищённая панель
управления. Хранение данных — в S3 (Timeweb Cloud) либо локально. Backend на
Node.js (Express); подпись S3-запросов реализована на встроенных модулях, без
внешних зависимостей.

---

## Доступ к панели управления
- Адрес панели: `https://ваш-домен/aaddmm` (неочевидный путь, меняется переменной
  `ADMIN_PATH`). Ссылок на панель на сайте нет.
- Вход по логину и паролю. Логин по умолчанию — `SP2026`.
- Пароль в коде не хранится в открытом виде — только как необратимый scrypt-хэш.
  Переопределяется переменной `ADMIN_PASSWORD_HASH`.

### Безопасность входа
- Не более 3 попыток; далее вход блокируется на 24 часа (защита от подбора, в том
  числе с разных IP — счётчик общий).
- Каждая попытка (успешная и нет) пишется в журнал с IP и временем — вкладка
  «Входы и безопасность».
- Токен-сессии с ограниченным сроком, тайминг-безопасное сравнение, ограничение
  частоты запросов, заголовки безопасности (CSP, X-Frame-Options и др.).

### Сменить логин или пароль
Задайте переменные окружения при деплое:
- `ADMIN_LOGIN` — логин.
- `ADMIN_PASSWORD_HASH` — хэш пароля. Сгенерировать:
  ```bash
  node -e "const c=require('crypto');const s=c.randomBytes(16).toString('hex');console.log(s+':'+c.scryptSync(process.argv[1],s,64).toString('hex'))" "ВАШ_ПАРОЛЬ"
  ```
  Полученную строку `salt:hash` вставьте в `ADMIN_PASSWORD_HASH`.
- `ADMIN_PATH` — путь к панели (например, `/my-secret-panel`).

## SEO-архитектура (страницы категорий и товаров)
Сайт готов к продвижению в Яндекс и Google. Кроме лендинга (`/`) сервер отдаёт
серверно-отрендеренные страницы (SSR) — их видят поисковики без выполнения JS:

- `/catalog/` — страница каталога со списком опубликованных категорий.
- `/catalog/<slug>/` — страница категории (H1, title, description, canonical,
  Open Graph, BreadcrumbList, SEO-текст, список товаров, фильтр по бренду).
- `/product/<slug>/` — страница товара (H1, title, description, canonical, Open
  Graph, Product Schema, BreadcrumbList, галерея с увеличением, характеристики,
  преимущества, описание, ссылка на категорию, похожие товары).
- `/sitemap.xml` — генерируется автоматически из опубликованных категорий и
  товаров (плюс главная и `/catalog/`). Публичный, но только на чтение.
- `/robots.txt` — генерируется автоматически, содержит `Sitemap:` и запрещает
  индексацию `/aaddmm`, `/api/`, `/uploads/`.
- Несуществующий или снятый с публикации товар/категория отдаёт HTTP **404**.

Всё это — **универсальные шаблоны**: один шаблон категории и один шаблон товара
на все категории и товары. HTML-файлы для товаров вручную создавать не нужно.

### Как формируется URL
URL берётся из поля **slug**. Если оставить slug пустым, он создаётся
автоматически из названия (транслитерация кириллицы, напр. «Лодочные моторы» →
`lodochnye-motory`). Slug можно задать вручную в админке. После создания slug
менять не рекомендуется (URL изменится) — но система это позволяет.

### SEO-поля
У категории и товара есть поля **SEO title** и **SEO description**. Если их не
заполнить, заголовок и описание формируются автоматически из названия, категории
и цены — без переспама. Product Schema использует только реальные данные: если
нет цены — блок offers не добавляется; рейтинги, отзывы и артикул не выдумываются.

### Абсолютный домен для canonical / sitemap
По умолчанию домен берётся из запроса (работает на домене Timeweb сразу). Когда
подключите свой домен, задайте переменную `SITE_URL` (например
`https://spacexten.ru`) — она будет использоваться в canonical, Open Graph и
sitemap.


На App Platform файловая система контейнера временная — при передеплое локальные
файлы пропадают. Поэтому проект хранит всё во внешнем S3: и базу (`data.json`), и
загрузки (фото, баннеры, логотип, PDF, иконки), и резервные копии. Так данные
переживают любой передеплой.

Переменные окружения (раздел «Переменные» приложения):

| Переменная      | Пример                     |
|-----------------|----------------------------|
| `S3_ENDPOINT`   | `https://s3.twcstorage.ru` |
| `S3_BUCKET`     | имя-вашего-бакета          |
| `S3_ACCESS_KEY` | ваш Access Key             |
| `S3_SECRET_KEY` | ваш Secret Key             |
| `S3_REGION`     | `ru-1`                     |

Когда заданы все пять переменных, проект автоматически использует S3 (path-style
адресация, нужная для Timeweb). Ключи в коде не хранятся. Secret Key храните в
секрете; при утечке перевыпустите его в панели Timeweb.

Если переменные S3 не заданы, проект работает локально: база в `data/data.json`,
файлы в `uploads/`.

В бакете: `data.json` (вся база), `uploads/…` (файлы), `backups/…` (копии).

## Резервные копии
- Создаются автоматически раз в сутки; хранятся последние 30 (старые удаляются).
- Вкладка «Резервные копии»: создать вручную, скачать, восстановить, удалить.
- Вкладка «Настройки»: экспорт всей базы одним файлом (скачивается в браузере) и
  импорт из файла.

## Аналитика
Вкладка «Аналитика»: всего посещений, уникальных посетителей и отдельный счётчик
переходов в корзину. Считается лёгким способом, без нагрузки на сайт.

## Уведомления в Telegram (заказы и заявки)
Бот присылает в Telegram каждый новый заказ и заявку на опт со всеми данными
покупателя (имя, телефон, состав заказа, сумма, способ получения, комментарий).
Так как Telegram может быть недоступен из РФ, поддерживается **прокси**. Все
секретные данные задаются только в переменных окружения Timeweb и **не
хранятся и не показываются в панели**.

### Шаг 1. Создать бота и получить токен
1. В Telegram напишите боту **@BotFather** команду `/newbot`.
2. Задайте имя и username бота. BotFather пришлёт **токен** вида
   `1234567890:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxx` — это `TELEGRAM_BOT_TOKEN`.

### Шаг 2. Получить chat ID (куда слать уведомления)
Вариант А — лично вам в личку:
1. Напишите вашему боту любое сообщение (например `/start`) — обязательно, иначе
   бот не сможет вам писать.
2. Напишите боту **@userinfobot** — он пришлёт ваш числовой **ID**. Это
   `TELEGRAM_CHAT_ID` (например `483912345`).

Вариант Б — в группу (заказы видит вся команда):
1. Создайте группу, добавьте туда своего бота.
2. Отправьте в группе любое сообщение.
3. Откройте `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` и найдите
   `"chat":{"id":-100...}` — это ID группы (со знаком минус). Это
   `TELEGRAM_CHAT_ID`.

### Шаг 3. Прокси (если Telegram заблокирован на сервере)
Подойдёт HTTP или SOCKS5 прокси с доступом к Telegram:
- `TELEGRAM_PROXY_TYPE` — `http` или `socks5`;
- `TELEGRAM_PROXY_HOST` — IP или домен прокси;
- `TELEGRAM_PROXY_PORT` — порт;
- `TELEGRAM_PROXY_USER` / `TELEGRAM_PROXY_PASS` — логин и пароль (если прокси с
  авторизацией; без авторизации — оставьте пустыми).

Если прокси не нужен — эти переменные не задавайте, бот подключится напрямую.

### Шаг 4. Куда вписать переменные (Timeweb)
Timeweb Cloud → приложение → **Настройки → Переменные окружения** → добавьте:

| Переменная             | Пример / значение              |
|------------------------|--------------------------------|
| `TELEGRAM_BOT_TOKEN`   | `1234567890:AAE...`            |
| `TELEGRAM_CHAT_ID`     | `483912345` или `-100123...`   |
| `TELEGRAM_PROXY_TYPE`  | `http` или `socks5` (если есть)|
| `TELEGRAM_PROXY_HOST`  | `123.45.67.89`                 |
| `TELEGRAM_PROXY_PORT`  | `8080` / `1080`                |
| `TELEGRAM_PROXY_USER`  | логин прокси (если есть)        |
| `TELEGRAM_PROXY_PASS`  | пароль прокси (если есть)        |

Сохраните и **передеплойте** приложение.

### Шаг 5. Проверить
`/aaddmm` → **Настройки** → блок «Уведомления в Telegram»: виден статус
(подключён / не настроен, есть ли прокси). Нажмите **«Отправить тестовое
сообщение»** — в Telegram придёт тест. Галочками включаются/выключаются
уведомления о заказах и заявках по отдельности.

> Токен, chat ID и данные прокси нигде в интерфейсе не показываются и не
> хранятся в базе — только в переменных окружения. Если тест не проходит —
> обычно дело в прокси (нет доступа к Telegram) или вы не написали боту `/start`.

## Возможности сайта
- Шапка-полоса синим градиентом с белыми кнопками; логотип-картинка или текст;
  слайдер с настраиваемым размером; фоновый баннер.
- Каталог: категории (синие) и подкатегории (оранжевые), поиск.
- Карточка товара: фото показывается полностью (без обрезки), увеличение по клику
  с листанием стрелками/свайпом, описание, выделенные цветом сопутствующие товары,
  инструкция собственная или привязанная из раздела «Инструкции».
- Слайдер баннеров со стрелками и точками в стиле интерфейса.
- Уведомления о заказах и заявках в Telegram (с поддержкой прокси).
- Корзина с оформлением заказа (самовывоз/доставка).
- Плавающие соцсети справа снизу.
- Перестановка блоков и вставка баннеров, редактирование всех текстов.
- Смена цветов градиентов; светлая тема по умолчанию, есть тёмная.
- Адаптация под телефоны и ПК.

## Быстрый старт (локально, без S3)
```bash
docker compose up -d --build
```
Сайт: http://localhost:3000 · Панель: http://localhost:3000/aaddmm (логин `SP2026`).

## Деплой на Timeweb App Platform
1. Соберите приложение из архива (Docker).
2. В «Переменных» задайте пять `S3_*` переменных (и при желании `ADMIN_LOGIN`,
   `ADMIN_PASSWORD_HASH`, `ADMIN_PATH`).
3. Порт задаётся платформой автоматически (приложение слушает `PORT` на `0.0.0.0`).
4. Данные в S3 — тома подключать не нужно.

## Деплой на обычный сервер (VPS)
```bash
unzip spacexten.zip && cd spacexten
docker compose up -d --build
```
Порт 3000. Данные — в S3 (если заданы переменные) либо в томах `data/` и `uploads/`.

## Рекомендуемые размеры изображений
- Логотип шапки: 600 × 200 px (PNG с прозрачным фоном / SVG).
- Фоновый баннер шапки: 1920 × 1080 px.
